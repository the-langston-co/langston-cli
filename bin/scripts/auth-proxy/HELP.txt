Usage: langston auth-proxy <COMMAND>

Available commands:
    check <ENV> - check that the Auth Proxy is running and its tunnel reaches Cloud SQL. Exits non-zero when it does not.
    help - show details about the commands that are available
    install - installs Google Auth Proxy
    start <ENV> [--login] - start the connection (ENV defaults to prod). From a terminal it signs you in to Google first when your sign-in is missing or has expired. --login does the same when there is no terminal.
    start-stage - start the stage connection
    stop <ENV> - stop the Auth Proxy service
    restart <ENV> [--login] - stop and start the Auth Proxy. Safe to run from several sessions at once. Renews your Google sign-in first, like start.
