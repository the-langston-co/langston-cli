Usage: langston auth-proxy <COMMAND>

Available commands:
    check <ENV> - check that the Auth Proxy is running and its tunnel reaches Cloud SQL. Exits non-zero when it does not.
    help - show details about the commands that are available
    install - installs Google Auth Proxy
    start - start the production connection
    start-stage - start the stage connection
    stop <ENV> - stop the Auth Proxy service
    restart <ENV> - stop and start the Auth Proxy. Safe to run from several sessions at once.
